## 1. 安全 H2：硬编码 `/workspace/emowave-engine` → 脚本目录

安全审查指出：12+ 个文件 `sys.path.insert(0, "/workspace/emowave-engine")`，既让脚本在本机跑不了，又在 `sys.path[0]` 插入一个可被同名文件劫持的位置（import 劫持面），与「local-first、零服务器」定位矛盾。

**修法**：统一改为「脚本所在目录」
```python
sys.path.insert(0, str(Path(__file__).resolve().parent))
```
模块级目录常量（`OUTPUT_DIR` / `data_dir` 等）也由 `__file__` 派生。

**涉及 12 个文件**：`privacy_export.py` / `test_engine.py` / `test_recommender.py` / `benchmark_suite.py` / `crisis_protocol.py` / `data_simulator_v2.py` / `demo.py` / `evaluation.py` / `onboarding.py` / `performance_profiler.py` / `run_simulation.py` / `whitepaper_generator.py`。

**实证**：此前在本机 `import privacy_export` 因绝对路径根本跑不起来；改后
- `import privacy_export` → OK
- `pytest test_report.py --collect-only` → 6 tests collected（原先也因硬编码无法收集）
