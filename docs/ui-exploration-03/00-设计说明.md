## 1. 曲线：更柔和，但比原来更严谨

### 做了什么
相邻两个模型点之间用 **单调三次 Hermite 插值**（Fritsch–Carlson）连接。

- 曲线**穿过每一个模型点**，不改变任何模型值；
- 单调性被强制保留 → **不可能凭空造出一个峰或谷**；
- 斜率限制在 3 倍割线以内 → 没有过冲（overshoot）；
- 置信带的上下界用同一套插值，所以带宽也是平滑的。

### 为什么这是"绘制"而不是"造数据"
内核给出的 Matérn 3/2 后验均值本身就是光滑函数，`curve_payload` 只在观察时刻采样
（今天 11 个点 + 5 分钟尾巴 300 个点）。之前的折线是**采样分辨率**的问题，
不是模型粗糙。把已知采样点之间如实连接，不引入任何新信息。

**没有做**：对原始观察点平滑、改预测、改方差、为了让曲线好看而移动点。
观察点仍是原值画的小圆点；修正仍是空心方框；外推仍是虚线。

### 视觉上的"柔和"
线宽 1.3px、圆头圆角、墨色而非纯黑；置信带是 10% 的蓝雾（不是灰块）。
曲线不再是"一根折线+一块灰"，而是一条**流动的痕迹**。

## 2. 基线：从一条线升级成"常态带"

### 它不是新造的统计量
`console_presenter._diff_from_baseline` 里已经写着：**|差| ≤ 2 视为"与基线持平"**。
所以轴上的"常态"本来就不是一个点，而是一条 ±2 的区间。这一轮只是把这条已有的产品规则**画出来**：

- **主屏的点线 + 两行字**：「常态 / 55」贴在轴左侧（轴上那个圈 ±2 的蓝色括号已按你的反馈删除——
  它更像"选中框"而不是刻度，反而让基线变重）；
- **模型页的标尺**：浅蓝块圈住 53–57，这是常态带的放大版，也是唯一的编辑入口；
- **历史页的水平偏差条**：每一段的峰值相对这条带的位置（低 25 / 高 3）。
  ±2 的规则改由"模型页的标尺 + 历史页的偏差条"承担，主屏只留最轻的一条点线。

同一条规则在三个页面用三种尺度表达，这是"特色"的来源——不是加装饰，而是
**让同一个概念在不同层级都成立**。

### 为什么标签放在轴左侧
8pt 中文实测「常态」= 26px，单行「常态 55」需要 51px，而轴左侧只有 38px ——
单行一定会被裁掉第一个字。所以拆成两行，且完全落在水位线起点（轴线）之外，
即使当前值恰好等于常态也不会叠字。

## 3. 当下：三层同时指向同一件事

1. **字**：26px「平静 · 偏积极」——回答"是什么"；
2. **数**：26px 蓝色「60」——回答"多少"，与水位线同色，是同一个语义单元；
3. **线**：贯穿全幅的 2px 蓝线——回答"在哪"，是画面里唯一的高饱和元素。

三者纵向相邻，视线不用跳。之前的版本把数字埋在四个并列读数里，
现在四个读数只剩三个（唤醒/置信/±1σ）做注脚——效价被提升到标题层，不再重复。

## 4. 蓝色：一条可执行的语义规则

**蓝 = 位置。** 具体只有四处：

| 位置 | 用法 | 对比度 |
|---|---|---|
| 水位线 + 当前值 | 2px 线 / 26px 数字 | `#3A6A88` 对纸 5.35:1 |
| 常态带 / 括号 | 面 + 1px 线 | `#2A5570` 文字 7.32:1 |
| 记录中的控制带 | 整条反相（底 `#1B374A`） | 白字 12.41:1 |
| 修正方框 | 1px 空心方框 | 修正会改变位置，所以同族 |

其余一切——状态句、曲线、观察点、时间刻度、说明行——都是中性灰。
**蓝色面积在一屏里不超过 3%**，它出现的地方就是"你现在在哪"。

中性文字只有三级（实测）：`#1A1A1A` 15.96、`#4D4D4D` 7.75、`#6E6E6E` 4.68。
`#B0B0B0` 只有 1.99:1，**只许画线**——这条在 02 里踩过，写进 00 的护栏建议。

## 5. 三页：同一套语言，不是三套皮肤

| | 主屏 | 模型页 | 历史页 |
|---|---|---|---|
| 竖轴 | 0–100 效价轴 + 常态括号 | 同一条轴，放大成可调的尺 | 无（改用每行一条水平偏差条） |
| 水平基准 | 常态点线 + 水位线 | 常态步进器（− 55 +） | 每行中线 = 常态 |
| 数字 | 右对齐等宽 | 右对齐等宽 | 右对齐等宽 |
| 分隔 | 1px 线 | 1px 线 | 1px 线 |
| 强调 | 蓝（位置/主操作） | 蓝（常态） | 蓝（峰值） |
| 卡片 | 无 | 无 | 无 |

- **模型页**：「你的常态」是一个真实控件——`− 55 +` 步进器 + 横向尺，
  尺上的浅蓝块就是主屏那条点线的放大版；下面是「个人模型」四行（已学习 / 惯性 ℓ / 阶段 / 个人化），
  再下面是参数说明。整页只用标尺与细线，没有一张卡片。
- **历史页**：按天分组，每行 = 时间区间 + 水平偏差条 + 峰值 + 偏差文字（低 25 / 高 3）+ 自评次数。
  偏差条以**中线=常态**，向左是低于、向右是高于；它是**行内放大显示**，不用于跨行比较绝对值
  （峰值数字仍在右侧）。
- 两页都包在滚动容器里：400×680 下不滚动，360×600 下可滚，**不裁字**。

## 6. 保留 / 未做 / 待你确认

**保留**：全部功能与数据语义、纠正上滑框（生产组件原样复用，只是配色跟随）、
生产内核与测试。生产 769 条测试仍全绿。

### 悬浮窗（本轮补上）

360×134 收起 / 360×180 展开，与生产同尺寸。它不是主屏的缩小版：

- 只留三样：状态句（14px）、当前水位（18px 蓝）、曲线；
- **常态在窗内不写字**，用同色的**点线**与水位线（实线）配对——一眼看出"我在哪、我的常态在哪"；
- 展开才出现置信/区间/时间刻度；记录时左下角变成"正在记录 · 已记 N 次"，右侧变成"■ 停止"；
- 窗内没有 0–100 标签，所以纵轴按当段自适应（±6% padding），只用来读形状；
  绝对位置由右侧数字与主屏的固定 0–100 轴提供，**不改任何数据**。

**这轮没做**：
- 深色模式（蓝色在暗底需要重新校准，属于下一轮）
- 空态 / 错误态的新版式
- 125% / 150% 缩放核对

**需要你确认**：
1. 「常态带」用 ±2 是否符合你对"持平"的直觉？（这个数字直接来自代码里的既有规则）
2. 当前效价 60 放在标题行右侧，和状态句同级——够不够"当下"？还是想让它更大？
3. 记录时整条控制带反相成深蓝，气场够强；会不会太抢？
4. 历史页的偏差条是行内放大，你能接受"不跨行比较绝对值"这个取舍吗？
5. 三页的密度是否合适（模型页偏信息型，历史页偏清单型）？
6. 悬浮窗的纵向自适应（没有 0–100 刻度，只看形状）你能接受吗？
   若想保留绝对高度感，改回固定 0–100 只需一行——代价是曲线在 60px 里几乎是平的。
