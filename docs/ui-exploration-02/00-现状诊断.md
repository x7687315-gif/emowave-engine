三角验证后的三条设计约束（≥2 个独立来源）：
1. **一条主信号优于一堆并列指标**（Nura 的定位 + Li 模型的"反思"阶段要求先看得懂）→ 支持把四读数降级。

3. **一屏多图会稀释反思**（EmoGlass 的多图堆叠 + 400px 窗口约束）→ 首屏只留一条曲线。

## 2. 已验证的问题（每条都有据可查）

### D1 · 最大的字不是"你现在怎么样"，而是数字
状态名 17px Medium，四读数 **18px** 等宽 Light（`windows/state_head.py`）。
用户在 400px 窗口里第一眼看到的是 60 / 46 / 91% / 46–73 四个并列数字，
而"平静 · 偏积极"比它们还小。**层级与产品含义相反**：状态是一个判断，数字是佐证。

### D2 · 四等权读数 = 没有主次
四个数字同字号、同字重、同列宽、同一灰度。用户无法从版面上知道
"效价是主线，唤醒/置信/区间是限定条件"。信息齐全，但没有结论。

### D3 · 卡片套卡片，边框是唯一的层级手段
- 曲线：页面底 → `#CurvePanel`（1px + 8px 圆角）→ 卡内标题栏 → 图表区，**四层**。
- 模型页 / 历史页：页面 → 卡片 → 卡内再套 1–3 个描边盒子（证据：
  `docs/screenshots/v5-model-400x680.png`、`v5-history-400x680.png`）。
把 1px 线全部去掉，页面立刻塌成一片 —— 说明层级从来没有真正建立，只是被画出来了。

### D4 · 图例代替了就地标注
卡标题右侧一行 5 项图例（`— 估计  ┄ 预测  · 观察  □ 修正`）：
它把"形状→含义"的对照做成了词典，用户得来回扫视；而曲线上每个语义其实都可以就地说明。

### D5 · 页头标题与卡片标题重复，且标题不随页面变
页头写死「情绪曲线」（`main_app.py:265`），切到**模型页 / 历史页仍然是"情绪曲线"**。
同一屏里还出现两次"情绪曲线"（页头 + 卡片标题），白占 24px 高度。

### D6 · 输入台常驻 20% 屏高，制造第二组竞争数字
双滑块 + `70/100` `57/100` 两个数字，与顶部四读数同级。
但用户绝大多数时间不在调滑块 —— 它占着首屏最贵的位置，却不是首屏要做的事。

### D7 · 垂直节奏均匀，没有"大留白 vs 密集"
44 / 40 / 133 / 270 / 139，像四块等重的砖。缺少疏密对比，所以既没有呼吸感，也没有重心。

### D8 · 状态切换不改变空间
从空闲到记录中，只有按钮文案、记一笔可用性、曲线多一段变化；
界面的**分量分布完全不动**。用户对"正在记录"这件事没有空间层面的感知。

### D9 · 预测在日尺度上不可辨识（本轮实测发现）
首屏时间窗约 7.5 小时，而外推上限 `MAX_DECAY_SEC = 600`（10 分钟）。
10 分钟只占窗口的 **2.2%**；本轮演示数据实际只推了 5 分钟 = **1.1% 宽度 ≈ 4px**。
虚线语义"存在"但看不见 —— 这不是配色问题，是**时间尺度问题**。
两套新方案都如实按时间比例画，并另用一行文字交代"预测 N 分钟"，不篡改时间轴。

### D10 · 窄屏降级靠"藏"，不靠"重排"
360px 下：日期隐藏、纠正按钮缩成「纠正」、状态提示隐藏（`main_app.py` / `state_head.py` 的 `resizeEvent`）。
这是在删信息，而不是换一种排法。证据：`docs/screenshots/v5-main-360x600.png`。

## 3. 保留不动的部分（两套新方案都必须带上的功能与语义）

| 类别 | 内容 |
|---|---|
| 状态 | 中文状态名、模型估计时间、距上次自评多久、与基线的差 |
| 读数 | 效价、唤醒、置信、±1σ 区间 |
| 曲线 5 语义 | 观察点（实心圆）· 模型估计（实线）· 预测（虚线）· 修正（空心方框）· 基线（点线） |
| 置信带 | ±1σ（两套方案用不同画法，见 `01`） |
| 操作 | 开始/停止记录、记一笔、纠正（复用生产上滑框）、页签切换 |
| 数据 | 全部来自**真实内核**：`ConsolePresenter` + Matérn ν=3/2 + Kalman/RTS，演示数据 11 次自评 + 2 处拖点纠正 |

生产侧的 `curve_widget.py`、`state_head.py` 的算法与数据契约**一行没碰**；
新布局是自己写的绘制层，只消费同一份 payload。

## 4. 诊断结论（一句话）

> 当前首屏不是"没有设计"，而是**把每个部分都设计成了同等重要**：
> 四个数字一样大、五个区块一样重、六条边框一样深。
> 于是用户看到的是一张**读数面板**，而不是"我今天怎么样"。
>
> 本轮两套方案分别在两个不同的方向上重建重心：
> **A 把重心放在"这句话"上，B 把重心放在"这个位置"上。**
