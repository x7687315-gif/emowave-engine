## 0. 本阶段要解决的问题

Phase 1 的结论是：缺的 5 项（D）集中在“时间语义可见化”；Phase 2/3/4 已经补上读数时间、基线差、修正标记、挂件年龄与双窗一致性。Phase 5 剩下的不是“再加功能”，而是：

1. **视觉系统**：`theme.py` 仍是 `radius=0` 的硬边构成主义，与本阶段“柔和圆角”的决定冲突；局部 QSS 还散落硬编码。
2. **错误态**：DB 打不开、快照损坏、记录保存失败，目前只写日志或静默降级，用户看不到。
3. **缩放验收**：360×600 是最小尺寸，但尚未有测试证明不被裁切。
4. **悬停信息**：曲线是视觉主角，鼠标移上去却没有任何读数。
5. **接口收口**：主窗/挂件仍各有一处直接摸 presenter 内部，违反 ROADMAP 的停止条件。
6. **重复绘制**：`curve_widget.py` 的修正点绘制块存在两份同体代码，白画一遍。

### 1.2 调研结论（以及本阶段怎么用）

| # | 结论 | 来源 | 对本项目的动作 |
|---|---|---|---|
| R1 | QSS 的 `border-radius` 只对“由样式绘制背景”的控件可靠；自定义 `paintEvent` 的控件要么开 `WA_StyledBackground`，要么自己用 `QPainterPath` 画圆角。父级样式还会向子控件泄漏，建议用 `#objectName` 限定。 | Qt Style Sheets Reference；Stack Overflow 12116413 / 35333236 | `EmotionCurveWidget` 自绘圆角背景并裁剪；`QFrame#Section`/`#CurvePanel` 用 objectName 限定；不给所有 `QWidget` 加全局圆角。 |
| R2 | 顶层窗口的 QSS `border-radius` **不能改变窗口形状**；窗口要圆角，需要透明背景 + 容器/自绘，或用 mask。 | Python GUIs “Create Custom Title Bars for PyQt5” | 挂件窗口用 `WA_TranslucentBackground`，标题/底部条各自圆角，顶层自绘 1px 圆角边框；主窗保持系统标题栏，只圆内容卡片。 |
| R3 | Qt 5 的高 DPI 必须在 `QApplication` 构造前 `setAttribute(AA_EnableHighDpiScaling/AA_UseHighDpiPixmaps)`；分数缩放可能有瑕疵，图片要按 `devicePixelRatio` 生成。 | Qt High DPI 文档；Spyder #26218 | 保持现有启动顺序不动；曲线 pixmap 缓存已按 `devicePixelRatioF()` 生成；新增 360×600 验收与 DPR 冒烟。 |
| R4 | 自绘曲线做悬停，推荐自己处理 `mouseMoveEvent` + `leaveEvent` + `setMouseTracking(True)`，在 `paintEvent` 画十字线/读数；`QToolTip` 可用但容易闪烁，且与自绘坐标系不同步。 | Pure Qt chart tracking 仓库；Python GUIs FAQ | 新增自绘 hover 覆盖层（时间 + 值 + 语义），不使用 `QToolTip`；紧凑模式/纠正画布关闭悬停。 |
| R5 | SQLite 本身抗损坏；损坏多来自外部（多进程、文件覆盖、硬件）。检测用 `PRAGMA integrity_check/quick_check`；修复前先备份，不要自动删除用户数据。 | SQLite “How To Corrupt An SQLite Database File”；netdata #24225；AIOStreams #1045 | 打开库后做轻量 `quick_check`；失败则降级为 `db=None` 并显示文件路径与“先备份”建议；快照损坏只清快照、保留事件表。 |
| R6 | 时间序列预测评估必须用滚动起点（rolling origin），不能随机打散；按 horizon 分组算 MAE/RMSE；预测必须在观察发生前记录，不能用 RTS 平滑后的曲线反推“当时预测”。 | AutoGluon forecasting metrics；Microsoft Learn rolling origin；时间序列指标文章 | Phase 6 新增 `forecast_log`（因果预测，带 base/target），评估工具按 horizon 分组；评估文档明确“用户自评也有噪声”。 |

## 4. 实施记录

### 4.1 视觉系统：先修字体层级，再谈圆角

**截图暴露的真问题**：第一轮截图看起来“所有文字都消失了”。排查后确认是两件事叠加：

1. offscreen Qt 平台连普通 `QLabel` 都不渲染文字 → 视觉验收必须用 Windows 平台抓图；
2. 更严重的是**全局 QSS 的 `QWidget/QLabel { font-family; font-size: 12px }` 覆盖了代码里 `setFont()` 的层级字体**。状态名应该是 17pt、读数是 18pt、数字应该是 Cascadia Code，实际全被压成 12px；状态名的 `minimumWidth` 按 17pt 算，视觉上却是 12px，导致 360px 下提示语与标题重叠。

**修法**：
- `QWidget` 只保留背景/前景；`QLabel` 只保留透明背景/颜色。默认字体交给 `QApplication.setFont(app_font(10))`；代码里的 `setFont` 重新生效。
- 数字读数使用 `app_font_num`（Cascadia Code），状态名 17pt、读数 18pt，恢复信息层级。
- 输入台右侧 `50/100` 改为按 `QFontMetrics("100/100") + 8` 动态定宽——固定 64/78px 在字体回退下仍会裁掉首位。
- `StateHead` 在 <380px 时隐藏“· 模型估计”并收成「纠正」按钮；`MainWindow` 在 <380px 时隐藏日期，标题/精力按钮保持可读。
- 曲线标题缩为「情绪曲线」、图例保留四类语义；360px 下不再裁掉“□ 修正”。
- 迷你曲线是 sparkline：高度 <100px 时去掉 Y 轴数字与刻度留白，曲线铺满 58px；避免 100/50/0 叠在一起。
- 模型页参数说明从 4 列改为 2×2；模型/历史页边距 16→12，`LegacyEmbed` 内边距同步收窄；极端 DPI 下允许横向滚动兜底，绝不静默裁字。
- `widgets.py` 的 `CardFrame`/`app_font` 统一到 theme；`history_window` 的伪 f-string 修复。

### 4.2 柔和圆角

- `theme.METRICS` 新增 `radius=8`（卡片/面板）、`radius_sm=4`（按钮/输入框/滑杆）、`radius_mini=10`（悬浮窗）。
- 全局 QSS 的按钮/主按钮/危险按钮/输入框/列表/分组框/滚动条/滑杆全部走令牌；只有 Tab 底部 2px 指示条保留直角（导航语义）。
- `EmotionCurveWidget` 自绘圆角纸面并 `setClipPath`，避免方块盖住面板圆角；`#Section`/`#CurvePanel` 用 objectName 限定圆角。
- 悬浮窗：`WA_TranslucentBackground` + 顶层自绘圆角边框；标题条上圆角、底部条下圆角；收起时曲线区负责下圆角。截图 alpha 实测：四角 alpha=0，说明窗口形状真的被裁成圆角。
- 遗留 `widgets.py` 的 `CardFrame` 也改用令牌，不再各写一份硬编码。

### 4.3 错误态

| 场景 | 行为 | 证据 |
|---|---|---|
| 数据库打不开 | `DatabaseOpenError`（带路径）→ 外壳降级 `db=None` + `NoticeBar` 提示“本次记录可能无法保存” | `test_corrupt_database_raises_open_error`、`test_main_window_shows_db_open_error` |
| 数据库损坏 | 打开后 `PRAGMA quick_check`；失败在创建表前抛出，不自动删除用户数据 | `test_corrupt_database_raises_open_error` |
| active_wave / latest_state / corrections 快照损坏 | `SnapshotStore._notify` → `presenter.notice_changed` → 主窗提示条；同类只提示一次 | `test_corrupt_snapshot_emits_user_notice`、`test_main_window_shows_corrupt_snapshot_notice` |
| 事件落库失败 | 事件写入 `~/.emowave/pending/<event_id>.json` 恢复文件，并在提示条给出路径 | `test_event_save_failure_spills_recovery_file` |

`NoticeBar` 是主窗页头下方的可关闭提示条，不使用模态框；提示只包含“哪份数据、什么影响、怎么办”，不显示情绪数值。

### 4.4 曲线悬停

- `EmotionCurveWidget(show_hover=True)`：`setMouseTracking(True)`；`mouseMoveEvent` 找最近点，`leaveEvent` 清除。

- 语义判定：预测段优先；否则按原始观察/修正的距离取更近者；其余为估计。`compact=True`（迷你窗、纠正画布）关闭悬停。
- 纯函数 `hover_at(x, y)` 供测试，不依赖真实鼠标；`test_curve_hover_reports_semantics` 覆盖估计/观察/修正/预测四种。
