关键决定：全画面只有一个色相（陶土赭红）。模型线、当前点、记录按钮、进度条全部同一色，只靠明度和面积区分层级。 置信带用 accent 的 10% 透明，刻度/基线用同族暖灰——不引入第二个色相。 同时避开红=告警的语义问题：陶土色是暖橙红，读起来是"体温"而不是"危险"。

本轮补的交互缺口：① 之前全站没有任何 focus 态——键盘用户完全看不见焦点在哪，现在统一 2px 环且只在键盘操作时出现； ② 补了 active 按下反馈（原来只有 hover，点了没反应）； ③ 图标列从 <i> 改成语义化 <button>，可 Tab 聚焦（原来键盘根本到不了）； ④ 参数说明从 display:none 硬切改成 max-height 过渡； ⑤ z-index 从散落的 4/5/7/8 收敛成语义化变量； ⑥ 输入台数值改为 hover/focus 时才淡入，平时不占视觉重量。
07 · 「当前情绪状况」的命名规则 · 纠正交互
括号内的一句话状态由效价 × 唤醒两个维度落在哪个象限决定，不是主观文案：
象限条件状态命名
高效价 · 高唤醒V≥50 且 A≥50兴奋 · 活跃
高效价 · 低唤醒V≥50 且 A<50平静 · 偏积极（当前）
低效价 · 高唤醒V<50 且 A≥50紧张 · 焦虑
低效价 · 低唤醒V<50 且 A<50低落 · 疲惫
接近中性V 与 A 均在 45–55平稳
注：文案刻意不作诊断、不作评价（不用"好/坏"），只描述状态——情绪类界面避免评判性措辞。
纠正交互（已按你的要求改）：
1. 次要区的纠正滑块已删除，主界面不再有纠正控件。
2. 入口上移到「当前情绪状况（…）」右侧的一句话：· 情绪有误，点这里纠正（小圆点 + 发丝框，无下划线）。
3. 点击后上滑框从底部升起（高 356px，遮罩压暗上方），内含两条独立的曲线：效价与唤醒（共用时间轴，上下 small multiples）。
4. 拖动曲线上的任一点：光标跟随气泡实时显示效价与唤醒两个数值；一条虚线竖直辅助线贯穿两条曲线，保证改的是同一时刻；原位置留一个空心小圈，直观看到改动量。
5. 手动输入：右侧面板显示「选中的点 · 13:40」，两个输入框直接填效价/唤醒，下方标注原值对照。
6. 底部：已提交 N 条纠正 · 查看 / 取消 / 提交纠正。
7. 次要区整块已删除——基线主权（微调±/分叉/重置）从主界面拿掉，搬进抽屉作为首项。理由：日常调基线是极低频操作（也许一个月才一两次），不该常驻主界面。 8. 底部输入台只保留滑块，右侧的 "62 / 41" 重复数字砍掉——顶部读数条已经显示了一次，输入区不再重复。 ⚠️ 顺带暴露的一个实现缺口：现有 EmotionCurveWidget 虽然数据里有 model_v 和 model_a（效价/唤醒）， 但 只画了效价，唤醒从来没被可视化过。上滑框把唤醒单独画一条，正好补上。
