## 1. 产品定位 → 视觉语言

EmoWave 是**本地情绪状态应用**：帮用户观察、记录、理解自己的情绪变化。
它不是科研仪器（不能冷到拒人），也不是情绪社交产品（不能甜到轻浮）。

| 产品事实 | 视觉要求 | 落到哪 |
|---|---|---|
| 数据是"你这个人"的，不是任务清单 | 柔和、不评判 | 曲线连续平滑；禁用红色告警语汇 |
| 用户常在低落时打开 | 冷静、有支撑感 | 中性骨架承担 90% 画面，点缀色只说话 |
| 核心资产是那条曲线 | 曲线是主角 | 强调色只出现在曲线/选中/主操作 |
| 长期贴身使用 | 耐看不刺眼 | 低饱和、无渐变、无玻璃拟态、无弹跳动效 |

**共同骨架**：黑 / 白 / 石墨灰 / 浅灰建立全部层级；金色或蓝色**只做语义点缀**。
层级靠**明度与面积**表达，不靠描边堆叠、不靠卡片套卡片、不靠阴影。

## 2. 公平比较契约（本探索的方法论）

A 与 B 必须**只在色板上不同**。以下逐项锁死，且由 `fairness_check.py` 断言：

| 维度 | A 与 B 是否相同 | 依据 |
|---|---|---|
| 窗口尺寸（400×680 / 360×600 / 360×180 / 360×134 / 400×480） | ✅ 逐像素相同 | manifest `shots[].content_px` |
| 区块高度（页头 44 / Tab 40 / 状态头 133 / 曲线 270 / 输入台 139） | ✅ | manifest `geometry` |
| 字体族与字号层级 | ✅ | manifest `ui_font` |
| 圆角（8 / 4 / 10）、线宽、点径 | ✅ | `apply_palette()` 内 `assert` |
| 演示数据（11 次自评、4 条纠正、15 个曲线点、同一基线与读数） | ✅ | manifest `n_*` / `curve_ts` / `readout_*` |
| 组件集合与交互流程 | ✅ 复用同一批生产类 | 未新增任何控件 |
| **只有语义色板、中性色温、明暗层次** | ❌ 允许不同 | 这就是要比较的东西 |

> 唯一一处"看起来像偏心"的地方已消除：置信带 alpha **两套严格相同**
> （亮 0.10 / 暗 0.15）。实测两方案的"带 vs 纸面"分离度 1.14 vs 1.15，
> 所以 A 暗色下更"闷"是**色相观感**差异，不是对比度差异——不许用调 alpha 掩盖。

### 3.1 两套中性轴的差别（唯一被允许的结构外差异）

- **A**：中性轴**严格无色偏**（R≈G≈B）。金色是画面里唯一的彩色 → 点缀色的语义权重最高。
- **B**：中性轴统一带蓝相（B > R）。整块画面像同一束冷光下的不同深度 → 更"成套"，
  但强调色与背景的**色相距离更小**，靠明度撑层级。

明度层级一一对齐（同层级同 L*），所以不存在"B 的底更亮所以更好看"。

### 3.2 暗色不是反色：三条校准规则

| 规则 | 亮色 | 暗色 | 为什么 |
|---|---|---|---|
| 高度方向 | `surface` 比 `paper` **亮** | 仍然更亮，但整体压在低明度区 | "靠前=更亮"在两种模式下都成立 |
| `accent_deep` 方向 | 同色相**加深** | 同色相**提亮** | 暗色没有向下空间，按下去会像消失 |
| `accent_soft` | 浅色 tint | **暗色** tint（#2B2617 / #162935） | hover 底必须是"更深的同族"，不能是亮块 |
| 文字对比度 | ink 15.4 / 17.2 | ink 14.5+ | 暗色下白字在深底上天然高，风险在 `muted` |

## 5. 形状、间距与线宽（结构令牌，A/B 相同）

| 令牌 | 值 | 用在 |
|---|---|---|
| `radius` | 8 px | 曲线面板、Section 卡片、列表 |
| `radius_sm` | 4 px | 按钮、输入框、滑块、tooltip |
| `radius_mini` | 10 px | 悬浮窗（顶层透明 + 自绘圆角） |
| `tabbar_h` / `topbar_h` | 40 / 44 px | 导航与页头 |
| 曲线线宽 | model 2.0 · forecast 2.0 · correction 1.2 · baseline 1.0 | 语义靠**形状+虚实**，不靠粗细 |
| 观察点半径 | 2.2 px | 小 = "我说的一句话"，不抢线 |
| 动效 | `EASE_OUT` 130 / 220 / 320 ms | 只用于淡入与状态切换，**绝不回弹** |

**"克制平滑曲线"作为主视觉资产**：曲线由内核 Matérn ν=3/2 状态空间平滑
（RTS 平滑 + 因果 Kalman），绘制端只做抽稀与抗锯齿——**没有任何为好看而加的二次平滑**。
这条是产品底线：平滑只能改善表达，不能修改模型输出或制造虚假峰值。
本轮两套方案都直接复用 `curve_widget.py`，曲线形状逐点相同。

## 6. 状态色语义（两套共用同一套角色分配）

| 状态 | 角色 | 令牌 | 说明 |
|---|---|---|---|
| 静默/待记录 | 中性 | `ink` / `muted` | 不催促、不评判 |
| 记录中 | 强调填充 | `accent` 底 + `surface` 字 | 「■ 停止记录」 |
| 衰减推演 | 弱化中性 | `rule` 底 + `muted` 字 | 「◌ 推演中…」禁用，不假装可点 |
| 悬停/选中 | 强调浅底 | `accent_soft` | 面积 ≤ 单个控件 |
| 按下 | 同族极值 | `accent_deep` | 暗色下方向反转 |
| 键盘焦点 | 强调描边 | `accent_ink` | 无障碍必须可见（见 H1） |
| 危险（重置） | 同族极值 | `danger = accent_deep` | **不引入红色**：情绪数据不该被"报警色"评判 |
| 错误提示条 | 中性 + 强调描边 | `paper_2` 底 + `accent_ink` 字 | `notice_bar` 可关闭，不弹模态 |

> `danger` 沿用生产的"同色相加深"约定，不新增色相。这让 A/B 保持可比，
> 也符合"不评判用户"的定位——但代价是重置操作缺乏直觉上的危险感，
> 记为 `02` §6 的开放问题，需要用户拍板。

## 7. 方案 A · 月光微金

**气质**：细腻、柔和、精致。
**一句话**：一张无色偏的银白纸上，只有"模型算的"和"你要按的"是金。

- 亮色：中性浅灰底 + 纯白纸面 + **暗香槟金**（#8A6D2E）。
  金色压深是**代价**：亮金做曲线漂亮但装不下白字按钮（实测 3.8:1），
  压深后同一支色同时满足曲线（4.9:1）与按钮（4.9:1）。
- 暗色：深石墨 + 柔金（#C7A55E）。金线在暗底上是本轮最好看的一处——
  但置信带合成后是 #39362F（偏橄榄），**观感发闷**（数值上达标，见 §2）。
- 风险：金色在 Windows 默认字体回退下与"警告黄"语义距离很近；
  大面积（曲线带 + 两个大读数 + 滑块 + 主按钮）叠在一起时，A 的**彩色面积感**明显大于 B。

## 8. 方案 B · 云白深海

**气质**：现代、冷静、清透。
**一句话**：同一束冷光下的不同深度，蓝只在水面亮起。

- 亮色：云白底（带一丝蓝）+ 纯白纸面 + **深海蓝**（#3A6A88，饱和度约 30%）。
  蓝天然比金暗，因此**同一个色值同时满足图形与小字**，无需压深。
- 暗色：深海黑（#0C1215，带蓝相而非纯黑）+ 亮海蓝（#6BA6C8）。
  置信带合成后 #243642，读起来像"水下的光"，不发闷。
- 风险：蓝 + 冷灰是**通用后台/监控仪表盘**的默认色，B 的"不像监控台"完全依赖
  低饱和与留白节奏；一旦有人日后把饱和度调高，B 会立刻掉进模板感。
  建议正式重构时把"accent 饱和度 ≤ 35%"写进护栏测试。

## 9. 实测质量底线（`contrast-report.md` 摘要）

| 方案 | 文字最差 | 图形最差 | 灰度分离最差 | 不达标项 |
|---|---|---|---|---|
| 生产（暖纸陶土） | 3.38:1 | 2.32:1 | 1.13:1 | **5** |
| A 亮 | 4.06:1 | 3.10:1 | 1.14:1 | 1 |
| A 暗 | 5.22:1 | 3.78:1 | 1.31:1 | 0 |
| B 亮 | 4.51:1 | 3.01:1 | 1.15:1 | 0 |
| B 暗 | 5.59:1 | 3.24:1 | 1.29:1 | 0 |

- A 亮唯一不达标项是**页头图标 hover 文字**（4.06:1）：Qt QSS 把 hover 前景写死成 `accent`，
  而金色无法同时满足"曲线够亮"和"浅底上的小字够深"。改成 `accent_ink` 即 5.93:1 达标
  ——这是一行 QSS 的角色分配错误，不是色板问题（详见 `03` §2）。
- 灰度分离列证明一件事：**四套曲线的语义都不依赖颜色**。把画面转成灰阶，
  模型线 / 观察点 / 基线 / 网格仍然分得开（置信带按设计就该弱，阈值单独设为 1.1）。
